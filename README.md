# 🌳 Drzewo binarne w C++

 > Prosty program w języku **C++**, który tworzy i wyświetla **drzewo binarne**.

---

 ## ⚙️ Funkcje

 - ➕ Dodawanie liczb do drzewa
- 🌳 Automatyczne rozmieszczanie elementów
- 🔢 Wyświetlanie elementów w kolejności rosnącej
- 🖥️ Graficzne wyświetlanie struktury drzewa w konsoli

---

 ## 🚀 Uruchomienie

 ### Kompilacja

```
g++ main.cpp -o drzewo
```

 ### Linux / macOS

```
./drzewo
```

 ### Windows

```
drzewo.exe
```

---

 ## 📌 Przykład

 Po dodaniu liczb:

```
5 3 7 2 4 6 8
```

 program wyświetli drzewo w konsoli oraz jego elementy w kolejności rosnącej.

 ### Przykładowe drzewo

```
        8
    7
        6
5
        4
    3
        2
```
